# Ascend Web

React and Vite Project Home for registered Ascend projects. Use root `justfile` commands only. Vite proxies same-origin `/api` traffic to the loopback API; the owned browser test overrides only that target.

Project Home loads exact four-field projects with a 5,000 ms bound and renders loading, empty, failure/retry, and deterministic `createdAt ASC, id ASC` card states. Its semantic `Open Project` form has a persistent `Host path` label and associated guidance for absolute, `~`, and `~/...` notation. The controlled value is preserved exactly. Blank input and all backend path categories publish an associated alert, set `aria-invalid`, retain input, focus the field, and change no card.

The registration client serializes `{"path":"<exact input>"}` once. Ordinary and retry requests have a 10,000 ms bound. While pending, duplicate activation is blocked and active Cancel is available. Created or existing responses upsert solely by stable ID, sort cards, scroll the exact returned action into view, focus it, and announce the disposition without reload. Equivalent paths therefore update one card rather than matching name or path text.

Only controlled positive pre-send unavailability is definitely not transmitted. After fetch invocation, timeout, connection reset or rejection, truncated or unreadable body, non-JSON, undocumented status, and invalid response shape enter announced `Submission outcome unknown`. The input and visible exact payload are locked; idle recovery exposes only `Retry same submission` and `Refresh projects`. Retry uses byte-equivalent JSON and active Cancel returns to the same locked state.

A valid refresh replaces the complete authoritative list and compares only IDs with the pre-submit snapshot. One added ID is focused and reconciled. Zero added IDs preserves authoritative cards, unlocks the original input, and announces no new project. Multiple additions preserve the complete list, select no identity, and require explicit reset before another payload. Failed, timed-out, or invalid refresh preserves current cards and locked payload. One monotonic request generation invalidates stale completion after every request, cancellation, timeout, refresh, reset, newer list, and unmount.

All path, payload, name, and canonical-path values render as inert complete whitespace-preserving React text. Card Open stays a stable-ID, keyboard-operable deferred action; it starts no workbench, request, or navigation. Picker, scanning, clone/import, project close, search, sorting controls, tags, path mutation, BL-010, and BL-012 remain deferred.

Validate with `just verify-open-project`, targeted `just verify-focused <test-path>`, and `just verify`. The keyboard-only desktop Chromium episode uses isolated database and host fixtures, proves created/equivalent/invalid/corrected/no-reload/deferred flows, checks fixture integrity, and removes exact owned process groups, listeners, database sidecars, and fixture roots on every modeled exit path. Sanitized passing evidence is generated at `test-results/bl-008/open-project/episode.json` and `cleanup-matrix.json`.
